# Design reference index

**Evidence levels:**
- `text`: page content fetched and read.
- `render`: loaded in Chrome; viewport screenshot viewed (scratchpad only, not committed).
- `styles`: computed CSS extracted from the rendered page.
- `not inspected`: the page could not be read; nothing is claimed about it.

All URLs were accessed on 2026-11-15.
